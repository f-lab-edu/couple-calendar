Couple Calendar(이하 "서비스")의 운영자 **정우병**(이하 "운영자")은 「개인정보 보호법」 등 관련 법령을 준수하며, 이용자의 개인정보를 안전하게 보호하기 위해 최선을 다하고 있습니다. 본 개인정보 처리방침은 운영자가 어떤 개인정보를 어떤 목적으로 수집·이용하며, 이를 어떻게 보호하는지를 설명합니다.

## 1. 수집하는 개인정보 항목

운영자는 서비스 제공을 위해 다음과 같은 개인정보를 수집합니다.

### 1.1 회원가입 및 인증 시 (Apple 로그인)

서비스는 별도의 비밀번호를 수집하지 않으며, Apple 로그인(Sign in with Apple)을 통해 회원가입 및 로그인이 이루어집니다.

| 구분 | 항목 | 비고 |
|------|------|------|
| 필수 | 이메일 주소 | Apple로부터 전달받음. Apple의 이메일 가리기(Private Relay) 사용 시 대체 이메일로 수집 |
| 필수 | 회원 식별자(UUID) | 인증 제공자(Supabase)가 발급하는 고유 식별값 |

> Apple 로그인 시 전달되는 ID 토큰(identityToken)은 본인 인증 검증 용도로만 사용되며 별도로 저장하지 않습니다.

### 1.2 프로필 정보 (이용자가 직접 입력)

| 구분 | 항목 |
|------|------|
| 필수 | 이름, 닉네임 |
| 선택 | 생년월일, 자기소개(bio), 프로필 이미지, 파트너 별명 |

### 1.3 서비스 이용 과정에서 생성·입력되는 정보

| 항목 | 설명 |
|------|------|
| 커플 연결 정보 | 커플 시작일, 파트너 연결을 위한 초대 코드(일정 시간 후 만료) |
| 캘린더 이벤트 | 제목, 시작·종료 시간, 종일 여부, 카테고리, 작성자, 설명(메모), 장소 |
| 기념일 | 이름, 날짜, 매년 반복 여부, 설명 |
| 알림 설정 | 이벤트·기념일·파트너 활동 알림 활성화 여부 및 알림 시점 |

### 1.4 자동으로 생성·수집되는 정보

| 항목 | 설명 |
|------|------|
| 서비스 이용 기록 | 데이터 생성·수정 일시(createdAt, updatedAt) |
| 인증 세션 정보 | 로그인 세션 토큰(암호화하여 쿠키에 저장, 유효기간 7일) |
| 접속 로그 | 보안 및 오류 대응을 위한 서버 접속·인증 검증 기록 `[⚠️ 법률 검토 필요 — 실제 서버 로깅 범위 확인]` |

> 서비스는 Google Analytics, Mixpanel 등 **별도의 행태정보 분석·광고 추적 도구를 사용하지 않으며**, 광고 식별자 또는 기기 식별자를 별도로 수집하지 않습니다.

## 2. 개인정보의 수집 방법

- 이용자가 Apple 로그인 및 프로필·이벤트·기념일을 직접 입력하는 과정에서 수집
- 서비스 이용 과정에서 자동으로 생성·수집(세션 쿠키, 처리 일시 등)

## 3. 개인정보의 수집·이용 목적

| 목적 | 처리하는 항목 |
|------|--------------|
| 회원 식별 및 본인 인증, 로그인 유지 | 이메일, 회원 식별자, 세션 토큰 |
| 커플 캘린더 핵심 기능 제공(일정·기념일 공유, 파트너 연결) | 프로필, 커플 연결 정보, 이벤트, 기념일 |
| 맞춤 알림 제공 | 알림 설정 |
| 서비스 안정성 확보 및 부정 이용 방지, 오류 대응 | 접속·인증 로그 |
| 법령상 의무 준수 | 관련 항목 |

## 4. 개인정보의 보유 및 이용 기간

원칙적으로 개인정보는 **수집·이용 목적이 달성되거나 회원이 탈퇴(계정 삭제)할 때까지** 보유하며, 이후 지체 없이 파기합니다.

| 항목 | 보유 기간 |
|------|----------|
| 회원 정보(프로필, 커플·이벤트·기념일·알림 설정) | 회원 탈퇴 시까지 |
| 로그인 세션 토큰 | 발급 후 7일(연장 가능), 로그아웃 시 즉시 삭제 |
| 관련 법령에 따라 보존이 필요한 정보 | 해당 법령에서 정한 기간 `[⚠️ 법률 검토 필요 — 통신비밀보호법·전자상거래법 등 적용 여부 확인]` |

회원 탈퇴 또는 계정 삭제 시, 해당 회원과 연결된 커플 정보·이벤트·기념일·알림 설정 등 관련 데이터는 함께 삭제됩니다.

## 10. 개인정보의 안전성 확보 조치

운영자는 개인정보 보호를 위해 다음과 같은 조치를 취하고 있습니다.

- **전송 구간 암호화**: 운영 환경의 모든 통신은 HTTPS/TLS로 암호화
- **세션 토큰 암호화**: 로그인 세션 토큰은 암호화(HMAC SHA-256)하여 HttpOnly 쿠키로 저장
- **접근 통제**: 모든 API 요청에 대한 인증 토큰 검증, 권한 기반 데이터 접근 제어
- **저장 데이터 보호**: 데이터베이스 저장소(Supabase) 암호화 적용

> 다만 어떠한 시스템도 100% 안전을 보장할 수는 없으며, 운영자는 합리적인 수준의 보호 조치를 위해 지속적으로 노력합니다.

## 11. 쿠키(Cookie)의 사용

서비스는 로그인 상태 유지를 위해 다음의 필수 쿠키 1종을 사용합니다.

| 쿠키명 | 목적 | 보안 속성 | 유효기간 |
|--------|------|----------|----------|
| session | 로그인 세션 유지(인증 토큰 저장) | HttpOnly, Secure(운영 환경), SameSite=Lax | 7일 |

본 쿠키는 서비스 제공에 필수적인 쿠키로, 거부 시 로그인 기능을 이용할 수 없습니다. 서비스는 광고·분석 목적의 비필수 쿠키를 사용하지 않습니다.
